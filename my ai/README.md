# 📊 المساعد الذكي لبيانات الإكسل (Excel AI Voice Assistant)

تطبيق ويب عصري، سريع، وخالٍ من المشتتات لتحليل ملفات الإكسل والتحدث معها بالصوت والنص، وتوليد رسوم بيانية تفاعلية وخرائط ذهنية (Mind Maps)، ومصمم ليعمل بسلاسة على متصفحات الهواتف الذكية (Android) وأجهزة الكمبيوتر.

---

## 🌟 المميزات
- **واجهة عصرية خفيفة:** تصميم داكن مريح للعين (Dark Glassmorphism) يدعم اللغة العربية تماماً.
- **تحدث بالصوت (Voice-to-Voice):** اضغط على المايك وتحدث بالعامية أو الفصحى، واستمع للرد بنطق صوتي طبيعي.
- **رسوم بيانية ذكية (Interactive Charts):** إنشاء تلقائي للرسوم البيانية (أعمدة، خطوط، دوائر) لتحليل أرقامك.
- **خرائط ذهنية (Mind Maps):** توليد مخططات انسيابية وخرائط ذهنية لاستراتيجيات وخطط العمل (Mermaid.js).
- **يعمل والكمبيوتر مغلق:** يمكن رفعه في دقيقتين على السحابة مجاناً.

---

## 🚀 تشغيل التطبيق محلياً على الكمبيوتر (للتجربة)

1. افتح موجه الأوامر (Terminal أو PowerShell) في مجلد المشروع.
2. قم بتثبيت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```
3. شغّل التطبيق:
   ```bash
   streamlit run app.py
   ```
4. سيفتح التطبيق تلقائياً في متصفحك على الرابط: `http://localhost:8501`.

## 📱 كيف تجعله يعمل 24 ساعة من الهاتف والكمبيوتر مغلق؟ (السحابة مجاناً)

لتحصل على رابط دائم تفتحه من هاتفك الأندرويد في أي وقت:

1. **ارفع المجلد على GitHub:**
   - افتح [GitHub.com](https://github.com) وأنشئ مستودعاً جديداً (New Repository) وارفع فيه ملفات هذا المجلد (`app.py`, `requirements.txt`, `.streamlit`, `sample_data.csv`).
2. **اربطه بـ Streamlit Cloud المجاني:**
   - افتح موقع [share.streamlit.io](https://share.streamlit.io) وسجل الدخول بحساب GitHub.
   - اضغط **New App** واختر المستودع الذي أنشأته، ثم اضغط **Deploy**.
3. **أضف مفتاح الـ API:**
   - في إعدادات التطبيق السحابي (Settings -> Secrets)، أضف السطر التالي:
     ```toml
     GEMINI_API_KEY = "مفتاح_جوجل_الخاص_بك"
     ```
4. **الآن على هاتفك:**
   - خذ الرابط الناتج (مثلاً `https://your-name.streamlit.app`) وافتحه من متصفح هاتفك أو أضفه للشاشة الرئيسية (Add to Home Screen) وكأنه تطبيق أصلي!
